- TypeScript 检查通过。抽帧改为全尺寸（`node review.mjs [帧号…]`），默认 55、175、290、500、710、950、1400、1740；另抽 92/93、352、690、779、1195、1610 看过渡。
- 对照 `shadows-neo` / `badges-chips` / `toggles-segmented` / `channel-cards`：外凸卡片为白高光 + 冷灰低光双色阴影；内凹井、内凹轨、按压态、选中态（内凹 + 3px 主色描边）均按配方放大约 2.5×；胶囊 chip 默认外凸、选中主色 + 内凹；分段控件为内凹轨 + 外凸滑块，编号 Geist Mono。
- 检查后修正：开场换色阈值从 0.5 提前到 0.3（白字在冷瓷上闪帧）；开场滑杆等擦拭结束后再出现；开场右侧蓝条改为擦拭留边，去掉与 wash 的接缝；胶片裁切对齐内凹井边缘；接力旋钮改 in-out 缓动。
